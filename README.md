# 📱 QR Drop Pro - ناقل الملفات عبر الـ QR Code

برنامج متكامل وسريع لمشاركة ونقل الملفات بين الكمبيوتر والهاتف فورياً باستخدام رمز الـ **QR Code** عبر الشبكة المحلية (Wi-Fi) بدون الحاجة لإنترنت خارجي، وبدون تثبيت أي تطبيقات إضافية على الهاتف!

---

## ✨ المميزات الرئيسية

1. **إرسال من الكمبيوتر إلى الهاتف (PC ➔ Phone):**
   - سحب وإفلات (Drag & Drop) لأي ملف أو حزمة ملفات.
   - توليد فوري لرمز QR Code عالي الدقة.
   - توجيه كاميرا الهاتف فقط نحو الكود لفتح صفحة التحميل وبدء التنزيل بأقصى سرعة للواي فاي.
   - دعم معاينة الصور والفيديوهات والملفات الصوتية والـ PDF مباشرة في المتصفح قبل التنزيل.
   - إمكانية تنزيل الملفات المتعددة بحزمة واحدة مضغوطة (`.zip`).

2. **استقبال من الهاتف إلى الكمبيوتر (Phone ➔ PC):**
   - مسح كود "بوابة الاستقبال" من الهاتف.
   - اختيار الصور أو الفيديوهات أو المستندات من الهاتف ورفعها بضغطة زر.
   - وصول الملفات إلى شاشة الكمبيوتر فوراً مع إشعار صوتي وبصري وحفظها في مجلد `uploads`.

3. **الكشف التلقائي عن الشبكة:**
   - كشف عنوان الآي بي (`LAN IP`) لشبكة الواي فاي تلقائياً (مثل `192.168.1.x`).
   - قائمة منسدلة للتبديل بين كروت الشبكة المختلفة (Wi-Fi أو Hotspot أو Ethernet).

4. **تحديثات حية (Live WebSocket):**
   - إشعار الكمبيوتر فور اكتمال تنزيل الملف على الهاتف أو استلام ملف جديد.
   - تنبيهات صوتية لطيفة (Web Audio API).

5. **إدارة وسجل الملفات:**
   - جدول تفاعلي يحتوي على عدد التنزيلات، الحجم، والتاريخ.
   - زر لفتح مجلد التنزيلات مباشرة على نظام ويندوز.

## 🚀 طريقة التشغيل

### الطريقة الأسهل:
فقط اضغط نقراً مزدوجاً على الملف:
```
run.bat
```
سيقوم البرنامج بالعمل وفتح واجهة لوحة التحكم تلقائياً في متصفحك!

### عبر سطر الأوامر (Terminal):
```powershell
cd d:\AntiyGravity\projects\qr-file-share
python app.py
```

ثم افتح المتصفح على:
`http://localhost:5005`

## 📌 ملاحظات هامة لنجاح النقل:
1. يجب أن يكون الهاتف وجهاز الكمبيوتر متصلين على **نفس شبكة الواي فاي (Wi-Fi)** أو نقطة اتصال الهاتف (Mobile Hotspot).
2. في حال ظهرت لك نافذة جدار حماية ويندوز (Windows Firewall) لأول مرة، اضغط على **"Allow access" / "السماح بالوصول"** على الشبكات الخاصة لتمكين الهاتف من الاتصال بالكمبيوتر.
